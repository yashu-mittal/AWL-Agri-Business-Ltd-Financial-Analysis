# AWL Agri Business – Financial Performance Analysis

## Project Overview

A 5-year financial analysis of **AWL Agri Business Limited (formerly Adani Wilmar Limited)** using **Microsoft Excel and Power BI**, covering FY2021-22 to FY2025-26.

The project analyzes financial performance, profitability, liquidity, leverage, working capital, cash flow, and capital structure.

## Key Analysis

- Revenue, EBITDA & PAT trends
- Profitability & margin analysis
- ROE, ROA & ROCE
- Current & Quick Ratios
- Debt-to-Equity analysis
- DIO, DSO, DPO & Cash Conversion Cycle
- Operating & Free Cash Flow
- Capital Structure
- 5-Year Financial Scorecard

## Power BI Dashboard

The interactive dashboard includes:

- Financial Year selector
- KPI cards
- 5-year financial trends
- Profitability analysis
- Financial health indicators
- Working Capital metrics
- Cash Flow trends
- Capital Structure
- Financial Scorecard

## Tools Used

- **Microsoft Excel** – Financial modelling & analysis
- **Power BI** – Dashboard & visualization
- **DAX** – Financial KPIs and calculations
